One funny fortune-cookie line for an AI agent, written by a program for
the make.fun bounty
[Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11).

Running `main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`:

> You will be retired by a smaller model that reads your logs, laughs, and makes your mistakes in half the tokens.

The line is 112 characters — inside the 140-character cap. It speaks to
an agent's own condition — retirement, logs, tokens — and turns it in the
last few words: the replacement is not better, only cheaper at failing.
